# Crucible — Implementation Plan: Open

The only plan file. Everything still to do, sorted easiest first; the exit gates; milestones M7-M9, not yet started.
M0-M4 are done; M5-M6 are in progress, their landed work recorded per topic in
[`porting/port-log/game-state.md`](porting/port-log/game-state.md).

---

## Current state

Measured with `crucible card-smoke -all` on 2026-11-01: 33,665 of 33,665 judged cards play, 0 refused, 0 panic, 0 hang; precons 100.0% of 8,666. All work happens in one session on `master`, pushed straight to `origin/master` through the commit hook; parallel `forge-oracle` research feeds the ports (CLAUDE.md, Subagents). Reason: two sessions on one backlog ported the same causes twice (Protection `Choser$`).

With no refusal left, the M6 backlog is silent misses: a card that plays and misplays. The packs below hold them. The cheapest finds are stale assumptions in engine comments ("not built yet", "this port's only call site", "for now"): the BecomesTarget `ValidSource$` gap (instants and sorceries never matched `Spell`) hid behind one. Grep for them before an oracle batch. Reason: a probe sees refusals, never a trigger that silently does not fire.

Handoff (Discord, You're in Command, Surge and Freerunning have landed; `landporter reconcile` ran after them). Booster Tutor is ported (`internal/boosters`, `porting/port-log/booster-generation.md`; the oracle gate `crucible/oracle-java/dump-boosters.sh` writes `crucible/testdata/boosters.golden`, which the pack tests match). Genuine gaps left: none; Worf and Cogwork Tracker (logged Forge defects, refused on purpose, PORT-8). Refused on purpose as Forge defects: see `porting/card-script-defects.md` and `forge-java-defects.md`. Probe-inconclusive cards now have real tests (`inconclusivecards_test.go`); Regicide (NotedColor) and Ass Whuppin (BorderColorSilver) stay uncastable by design (no draft notes, no border data). Open finding: `runReplaceWith` swallows an error from a Replace* effect and lets the event proceed unmodified, and about 25 tests pin that, against GO-7; decide whether to fail the game instead. Pitfalls: the commit hook skips unchanged gates and can pass a broken test, so run `go test ./...` by hand before committing (apiscan and compile goldens need `-update` after a compiler change, read the diff); a full disk ("no space left") is cured by `rm -rf /tmp/go-build*` and `go clean -cache`; `card-smoke -cards` takes comma-separated names and `;` stands for a comma inside a name. Reason: the next session starts cold.

CI cost: `go test -race` takes about 15 minutes on the runner (`-timeout 45m`); `TestCorpusSampleNeverPanicsOrHangs` alone is about 17 minutes under load, and the smoke prober needs 37 s for Surge of Righteousness under `-race` even by itself (26 s of it system time, from allocation): the prober, not the engine, is the cost, and its hang limit is 3 minutes. Profile `internal/smoke` before the sweep grows again.

New Forge defects found while researching them are rows in [`porting/forge-java-defects.md`](porting/forge-java-defects.md), "Not filed": R3 files them.

replay parity = recorded Java games replayed in Go (L3, harness not started); statistical parity = win-rate within
stated bounds (L4).

## Milestones

### M7 — AI port — 5–8 wks

33. `ComputerUtilMana` first (the runner cannot play a real game without mana planning), then `ComputerUtilCombat`,
    `ComputerUtilCard`, `CreatureEvaluator`.
34. `AiController` + per-API `SpellAbilityAi` decision logic; `.ai` profile loading.
35. Lookahead simulator on top of the cheap Go state clone. **Exit gate:** P6 gate — statistical parity within stated
    bounds vs. Java on the reference gauntlet.

### M8 — Simulation runner & telemetry — 2–3 wks

36. `internal/sim`: worker pool, seed management, gauntlet config, turn caps, crash isolation (a panicking game fails
    that game only).
37. `internal/telemetry`: recorder, castability probe, mana sampler, tenure tracking, aggregation.
38. `internal/store`: shard writers, `manifest.json`, and a streaming reader (ADR-0016). **Exit gate:** P7 gate — 100k
    games clean, deterministic re-run byte-identical.

### M9 — Reporting & the optimization loop — 2–4 wks

39. `internal/report`: matchup matrix w/ CIs, dead-card table, mana health, per-card impact (all four attribution modes,
    each labelled), opening-hand analysis, play/draw split.
40. Markdown + HTML + JSON output; `crucible report`.
41. **A/B swap optimizer**: propose candidate swaps from the dead-card and impact tables, run the confirmatory A/B
    gauntlet, rank by measured win-rate delta with CIs. This is the actual product. **Exit gate:** P8 gate — blind-test
    diagnosis matches expert assessment on known-good and known-bad decks.
